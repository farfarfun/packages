farfarfun 包仓库

加一次源，以后所有 farfarfun 的包都能直接 apt install。

加源

curl -fsSL https://farfarfun.github.io/packages/farfarfun.gpg \
  | sudo tee /usr/share/keyrings/farfarfun.gpg >/dev/null

echo "deb [signed-by=/usr/share/keyrings/farfarfun.gpg] https://farfarfun.github.io/packages/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/farfarfun.list

sudo apt update

装

sudo apt install fundeploy

支持 amd64 和 arm64。想装旧版本用 apt install fundeploy=0.3.0， 可选的版本见 apt list -a fundeploy。

其它渠道

brew install farfarfun/tap/fundeploy      # macOS / Linuxbrew
cargo install fundeploy                   # 有 Rust 工具链的话
curl -fsSL https://raw.githubusercontent.com/farfarfun/fundeploy/master/install.sh | sh

这个仓库怎么来的

索引由 farfarfun/packages 自动生成：各项目发版时把 .deb 挂在自己的 GitHub Release 上，这边按 packages.toml 收上来、重算索引、签名、发到 Pages。
